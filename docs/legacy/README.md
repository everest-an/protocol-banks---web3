# Legacy Documentation Archive

These documents describe the **payment-era product** (batch payments, TRON
integration, yield aggregation, enterprise payment flows, X402, settlement).

They are preserved for the **Business** feature set, which remains available
in the product but is no longer the hero. Documents here are NOT maintained
against the AI trading codebase and may be outdated.

For the current product see:

- [PRD v2 — AI Trading](../PRD_V2_AI_TRADING.md)
- [Usage Guide](https://protocolbanks.com/help)
- [Risk Disclosure](https://protocolbanks.com/risk-disclosure)
- [README](../../README.md)

The `zh-legacy-*.md` files are Chinese-language documents whose original
filenames were corrupted by an encoding issue; content is unchanged.
