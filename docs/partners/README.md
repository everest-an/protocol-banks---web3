# Card provider pack

Materials for Yativo / Rain due diligence:

| Document | Purpose |
|---|---|
| [CARD_PROVIDER_APPLICATION.md](CARD_PROVIDER_APPLICATION.md) | Application checklist, company profile template and send-ready messages |
| [KYB_SUBMISSION_TEMPLATE.md](KYB_SUBMISSION_TEMPLATE.md) | Fillable KYB form template (CI, address proof, directors/UBO, bank, declarations) |
| [AML_KYC_POLICY.md](AML_KYC_POLICY.md) | Program AML/KYC policy draft (issuer review required) |
| [SECURITY_OVERVIEW.md](SECURITY_OVERVIEW.md) | Non-custodial architecture, key management, limits, incident response, limitations |
| [CARD_PROGRAM_FLOW.md](CARD_PROGRAM_FLOW.md) | Actors, treasury vs per-user deposit models, controls, reconciliation |
| [Protocol-Bank-Card-Provider-Pack.pdf](Protocol-Bank-Card-Provider-Pack.pdf) | Print-ready pack of the three documents above |

Company registration, UBO, bank and contact details are **not** in this public
repository. They are provided separately in the signed KYB submission.
